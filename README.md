This project collects OLF MD simulations scripts.

Read <a href="https://pubs.acs.org/doi/abs/10.1021/acs.jcim.5c02828" title="This is the title/tooltip" target="_blank" rel="noopener noreferrer">Enhanced and Classical MD Simulations Map Aggregation-Prone Regions in the Olfactomedin Domain of Myocilin</a> paper.


Requirements:

Python 3.9 using lifelines (v0.27.4) and  pandas (v1.4.2) matplotlib (v3.5.2) and seaborn (v0.11.2) for visualization.
